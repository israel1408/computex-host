## 📌 What is ComputeX Clearhouse?

ComputeX Clearhouse connects creators and AI engineers directly with GPU machine owners. By running the ComputeX Host Daemon, your gaming rig or mining server securely leases spare GPU compute power during idle hours—earning you **daily USDC payouts** at an **80/20 platform revenue split**.
